# DadBod Cut Tracker

A simple local-first daily tracker for the Aug-Nov 2026 cut.

## Workflow
- Enter morning weight once daily.
- Log meals/snacks in plain English throughout the day.
- Meal category defaults from entry time but can be overridden.
- Receive lightweight guidance toward the current plan: moderate protein, fiber, hydration, portion control and trend-based weight decisions.
- Data is stored locally in the browser via localStorage.

## Run
Open `index.html` directly in a browser, or serve this folder with any static web server.

## Current plan defaults
- Calories: 2,100-2,300/day starting range
- Protein: 130-150 g/day
- Fiber: 25-35 g/day, increased gradually
- Goal checkpoint: November 7, 2026

This is a habit tracker, not medical diagnosis or treatment.
