# NovaForm

A mobile-first, local-first weight and meal tracker with a cosmic ultraviolet interface.

## Daily workflow
- Enter morning weight once daily.
- Log meals and snacks in plain English throughout the day.
- Meal category defaults from entry time but can be overridden.
- Receive lightweight guidance toward moderate protein, fiber, hydration, portion control and trend-based weight decisions.
- Follow the 7-day weight average rather than reacting to one weigh-in.

## Current plan defaults
- Calories: 2,100-2,300/day starting range
- Protein: 130-150 g/day
- Fiber: 25-35 g/day, increased gradually
- Goal checkpoint: November 7, 2026

## Privacy
Entries are stored only in the browser using localStorage. Each device/browser has its own independent history. There is no cloud account or shared database in this version.

## Sharing / GitHub Pages
This folder is published through the repository's NovaForm GitHub Pages workflow. Once deployed, open the public URL on iPhone and use **Share → Add to Home Screen** for an app-like experience.

This is a habit tracker, not medical diagnosis or treatment.
